# 📖 项目定位

TOM 是一个专为学习与研究场景设计的开源轻量级语言模型。

它以 小而全 为核心原则，能够在普通个人电脑（CPU 或单 GPU）上运行，同时保留主流大语言模型的关键功能。

无论是初学者想理解 LLM 架构，还是研究者需要一个可控、可改造的原型系统，TOM 都能提供清晰的代码和详细注释，帮助深入掌握原理与实现。

# 🎯 核心目标

- 学习导向：代码简洁且有完整中文注释，方便理解每个模块工作原理
- 小型可运行：在常规 PC 或轻量 GPU（如 RTX 3060）即可训练和推理
- 功能全面：支持从基础预训练到高级多模态与推理功能
- 易扩展：模块化结构，方便引入新算法、新任务和新数据类型
